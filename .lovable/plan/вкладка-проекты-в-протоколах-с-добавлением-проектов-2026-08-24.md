# Вкладка «Проекты» в протоколах с добавлением проектов

## Цель
Дать возможность добавлять проекты прямо на портале: отдельная вкладка «Проекты» в модуле протоколов, а список проектов в секциях внутри протокола берётся из этого же списка.

## Что будет сделано

### 1. База данных (миграция)
- Сейчас таблица `projects` позволяет только просматривать и обновлять записи — добавление новых запрещено правилами доступа.
- Добавлю правило: авторизованные пользователи портала могут добавлять проекты.

### 2. Хук `src/hooks/useProjects.ts`
- Добавлю мутацию `useCreateProject` (добавление проекта с автоматическим обновлением списков во всех местах портала).
- Существующая `useUpdateProject` уже поддерживает переименование и архивацию.

### 3. Вкладка «Проекты» в `ProtocolsModule.tsx`
- Новая вкладка «Проекты» рядом с «Протоколы совещаний» / «Тендер-протоколы» / «Строители».
- Содержимое вкладки:
  - Поле ввода + кнопка «Добавить проект» (с защитой от дублей по названию).
  - Список активных проектов (по алфавиту).
  - Для каждого проекта: переименование (иконка карандаша) и архивация.
  - Блок «Архивные проекты» с возможностью восстановления.
- Права: вкладку видят все, кто видит модуль протоколов; добавлять/переименовывать/архивировать могут пользователи с правами редактирования протоколов (тот же список, что для создания протоколов). Остальным — только просмотр списка.

### 4. Связка с протоколами (уже работает)
- Внутри протокола список проектов для секций формируется из таблицы `projects` через `useProjects` (архивные скрываются автоматически).
- После добавления проекта во вкладке он сразу станет доступен при добавлении секции «Проект» в любом протоколе — отдельных правок в редакторе не потребуется.

## Затронутые файлы
- Миграция БД: политика добавления в `projects`.
- `src/hooks/useProjects.ts` — новая мутация.
- `src/components/modules/ProtocolsModule.tsx` — новая вкладка и её содержимое (новый компонент `src/components/modules/protocols/ProjectsTab.tsx`).

## Проверка
- Добавление проекта во вкладке, его появление в списке выбора секций протокола.
- Архивация скрывает проект из выбора в протоколе, восстановление возвращает.
- Права: пользователь без прав редактирования видит список, но не может менять.
