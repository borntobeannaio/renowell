# Исправление ошибки «Протокол сохранён с ошибками» при пустых секциях

## Диагноз (подтверждён воспроизведением в браузере)

При сохранении протокола №74 в консоли 5 раз повторяется ошибка:

```text
Error: invalid input syntax for type uuid: "null"
at useTasks.ts (useUpdateTask)
```

Причина: у секций с компаниями без задач (пустые плейсхолдеры вида `[Неорос] `, `[Гемотех] `, `[Некст-т] `, `[Технополис] `, `[ФАРМСТЕР] ` — найдены в базе) нет связанной задачи (`task_id = null`) и нет текста. При сохранении код в `processSingleItem` попадает в ветку `else` и вызывает обновление задачи с `id: null`, что даёт ошибку 400 от базы. Каждый такой пустой пункт считается «не сохранённым», поэтому появляется тост «Протокол сохранён с ошибками (5 пунктов не сохранено)», хотя сами данные протокола сохраняются корректно.

## Изменение

**`src/pages/ProtocolEditor.tsx`** (строка 1765): заменить

```ts
} else {
  // Update existing task with current item data (sync all editable fields)
```

на

```ts
} else if (item.task_id) {
  // Update existing task with current item data (sync all editable fields)
```

То есть задача обновляется только если она реально существует. Пустые пункты-плейсхолдеры (компания без задач, пустая секция) просто сохраняют сам пункт протокола и не пытаются обновлять несуществующую задачу.

## Проверка

Повторить сохранение протокола №74 в браузере: ошибок 400 быть не должно, тост — «Все изменения сохранены», данные протокола не меняются.
